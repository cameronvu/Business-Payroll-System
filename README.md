# Business-Payroll-System
This is a backend Java system which is a means for creating 
employee data types (objects) and associating them with certain payment
plans (paid, unpaid, commissioned, or salaried). A program like this would 
be used by companies who wish to store data about all of their employees
and the form in which they are paid in a safe and in a protected manner. 
See the in-file documentation for an extensive description of individual
classes, data types, protected fields, and example corporation use.
